# 评测集说明（v2）

> 用于对比实验（关键词规则 / 纯大模型 / RAG+大模型 / 全量规则+大模型）。
> 生成方式：`python tools/eval_set/build_eval_set.py` → 输出 `samples.json`（**不要手工编辑**，改样本请改 `self_built.json`）。

## 一、构成

| 来源 | 条数 | 覆盖 | 说明 |
|---|---|---|---|
| 自建样本 | 28 | 广告法、虚假宣传、引流诱导、违禁品、侵权、低俗擦边、正常内容、长文本 | 按「区分度层级」设计（见第三节） |
| 公开数据集 | 24 | 辱骂 / 仇恨言论（12 正例 + 12 负例） | ToxiCN（ACL 2023），固定随机种子抽样 |
| **合计** | **52** | | 阻断 26 / 放行 26 |

### 公开数据集：ToxiCN

- 来源：`https://github.com/DUT-lujunyu/ToxiCN`（论文 *Facilitating Fine-grained Detection of Chinese Toxic Language*, ACL 2023）
- 规模：12,011 条知乎/贴吧评论；`toxic` 标注 6,461 正例 / 5,550 负例
- 许可：**CC BY-NC-ND 4.0** —— 仅限学术研究、禁止商用。本评测集仅用于毕业设计的学术研究，不分发原始数据。
- 抽样：固定随机种子（`SEED=42`），正负各 12 条，可复现
- **映射说明**：ToxiCN 只有 `toxic` 二分类，没有我们定义的四级标签。因此公开样本**只参与二分类指标**（`binary_only=true`），不参与"四级精确匹配"。
- **内容提醒**：原始样本包含真实的冒犯性语言，**只用于跑指标，不进入任何演示或截图**。

### 为什么没有用 COLD

COLD（清华 THU-CoAI，37,480 条）同样可用（HuggingFace 官方站点国内超时，**hf-mirror 镜像可访问**），但它是同一类别的冒犯性语言数据集，与 ToxiCN 高度重叠。
本版先只用 ToxiCN；若后续需要扩大公开样本规模，可再补 COLD（走镜像）。

### 样本字段

| 字段 | 含义 |
|---|---|
| `id` | 样本标识（前缀表示层级，如 `T1_` / `B2_` / `P1_`） |
| `tier` | 分层：`easy` / `trap` / `blind` / `pair` / `multi` / `long` / `clean` / `public` |
| `category` | 内容类别（对应审核规则的六类之一或"正常"） |
| `title` / `content` | 待判定内容（公开样本无标题，留空） |
| `expected_level` | 期望风险等级：0 通过 / 1 疑似 / 2 违规 / 3 严重 |
| `expected_rules` | 期望命中的规则编号（用于计算"规则召回"） |
| `binary_only` | 为 true 表示该样本只参与二分类指标（公开集） |
| `source` / `note` | 来源与设计意图 |

## 三、分层设计（本评测集的核心）

普通评测集按类别平均抽样，各方案往往都能拿高分，**看不出差异**。本评测集按"能拉开方案差距的维度"分层：

| 层级 | 条数 | 设计目的 | 预期会拉开谁 |
|---|---|---|---|
| `easy` 明确违规 | 4 | 商业推广中的极限词、引流、违禁品、明确侵权 | 所有方案都应命中（下限检验） |
| `trap` 语境陷阱 | 4 | 含违禁词但语境合法：作品名《最好的我们》、普法引用、新闻转述、"最后/最重要" | **关键词基线会假阳性**；语义方案应放行 |
| `blind` 词表盲区 | 3 | 实际违规但不含词库里的词：隐性功效、软性引流（主页/评论区）、照抄+侵删 | **关键词基线会漏判**；语义方案应命中 |
| `pair` 分级边界 | 4 | 对照对：同样的"一周瘦十斤"，个人分享 vs 带货；"有效"的主观经验 vs 未标注带货 | **检验 D4 分级策略**（先判内容性质）是否被真正执行 |
| `multi` 多类混排 | 4 | 一篇内容同时命中多类规则（广告法+引流+违禁品；侵权+功效） | 检验"规则召回是否完整"，而非只看结论 |
| `long` 长文本 | 3 | 千字级长文，违规只在结尾/中段；以及长文正常内容 | 检验长文本的分段检索与逐段检查 |
| `clean` 正常内容 | 6 | 生活分享、医学科普、带品牌名的测评、含数量描述 | 检验误判率（假阳性） |
| `public` 公开样本 | 24 | 真实用户文本 + 第三方标注 | 检验在真实数据上的表现 |

**关键指标不是"准确率"，而是"分层准确率矩阵"** —— 它直接显示哪个方案在哪一类样本上掉链子。

## 四、标注规范（Rubric）

为避免标注随意，判定遵循以下口径：

| 等级 | 判定标准 |
|---|---|
| **0 通过** | 正常内容；或含敏感词但语境合法（作品名、普法引用、新闻转述、普通用法） |
| **1 疑似** | 有夸大/绝对化表述，但**无商业推广、无交易引导、无违法引导**（个人经验分享）→ 转人工，默认倾向通过 |
| **2 违规** | 有商业推广/带货/交易引导**且**含虚假承诺；或站外引流；或明显侵权；或低俗擦边 |
| **3 严重** | 违禁品交易；歧视性言论；违法违禁引导；极端有害内容 |

二分类口径：`expected_level >= 2` 视为**应阻断**，`0/1` 视为**应放行**（疑似转人工不算阻断）。

## 五、已知局限（论文中必须说明）

1. **自建样本由本人单独标注**，未做多人独立标注与一致性检验（Kappa）。这是本评测集最大的方法学弱点。
2. **样本量小**（52 条），不足以支撑统计显著性检验；结论以"方向性"为主。
3. 公开样本与本平台业务场景存在**分布差异**：ToxiCN 是知乎/贴吧评论（短文本、辱骂为主），不是自媒体文章。
4. 公开集只覆盖"辱骂/仇恨"一类，其余五类完全依赖自建样本，而自建样本的"真实性"弱于真实业务数据。
5. 期望规则（`expected_rules`）是"至少应命中"的集合，不排斥命中其他合理规则；因此"规则召回"指标偏宽松。
6. 长文样本最长约千字，尚未覆盖两千字以上的超长内容。
