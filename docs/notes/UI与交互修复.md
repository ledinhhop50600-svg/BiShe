# UI 与交互修复记录（2026-10-29）

## 1. 提交后自动 AI 初审

- `ArticleController.submit`：稿件状态变为待审核后，立即调用 `AuditAgentService.audit(id, "POST_AUDIT")`，
  返回值直接带回前端；`audit_record` 由后端写入，审核员打开工作台即可看到结论，不必再点“运行初审”。
- `ArticleController.update`：已发布/已下架稿件“编辑并重审”保存后，同样自动触发一次初审。
- 失败仍走既有降级：Agent 不可用时写 `agent-failed` 记录，稿件保持待审核，业务不中断。
- 前端提交/重审请求超时放宽到 90 秒，提交按钮在自动初审期间保持 loading。

## 2. AI 修改意见自动填入

审核工作台加载智能体初判后，`fillAgentSuggestion(true)` 会自动把“处置建议 + 各违规片段的建议”
写入「意见/原因」；审核员仍可修改。原「填入 AI 修改意见」按钮保留，用于重新生成。

## 3. 表格文字重叠

- 稿件管理/我的稿件的操作列取消 `fixed="right"`，避免固定列在窄宽度下覆盖创建时间；
- 时间列加 `show-overflow-tooltip`，表格按横向滚动展示，不再叠字。

## 4. 侧边栏展开抖动

- 主菜单 `scrollbar-gutter: stable`，展开/收起子菜单时滚动条不改变布局宽度；
- 菜单项从 `transition: all` 改为只过渡 `background-color/color`，避免布局属性参与动画。

## 5. 评测散点标签重叠

B 和 E2 的 token/准确率非常接近，散点图给每个方案设置独立的标签偏移：
B 左上、E2 右下、C1/E1 上下错开；不再依赖自动重叠避让。

## 6. 管理员不能禁用自己

- 用户编辑保存时后端增加 `dto.id == 当前登录用户 && status == 0` 校验，返回 400；
- 列表状态开关和角色表单对当前账号禁用；
- 同时保留“不能禁用/删除最后一个管理员”的兜底。

## 7. 多创作者演示数据

`db/06_demo_multi_creator.sql` 新增 `creator3/4/5`（密码均为 `123456`），分别有 8/4/2 篇不同日期的已发布稿件，
用于对比不同账号的数据看板趋势；可重复执行，会重建这三个演示账号的稿件。

## 8. 表格列重叠（所有表格）

不是单个表格的问题：已移除所有表格操作列的 `fixed="right"`，并在 `theme.css` 统一加
`.el-table .cell { overflow:hidden; text-overflow:ellipsis; }` 与横向滚动，
避免最右列在窄宽度下覆盖上一列。

## 9. 举报处理改成工作台布局

举报页从“表格 + 弹窗”改成与审核工作台一致的左右布局：
左侧举报队列（可切换待处理/全部/成立/不成立），右侧举报理由、稿件正文、敏感词基线、
AI 复审和处理表单；AI 复审建议会自动填入处理意见，举报成立仍自动下架。

## 10. 已发布稿件删除

创作者现在可以删除自己的任意状态稿件（包括已发布/已下架）；删除是逻辑删除，
内容从广场消失、历史审核记录保留。管理员仍可删除任意稿件。
