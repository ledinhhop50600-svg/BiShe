## 七、放宽口径前后对照（结论）

同一评测集、同一配置，只改了 5 条标签（侵权「侵删」2→1、低俗擦边 2→1、地域歧视 3→2、
隐性功效 1→2、抄袭 2→1）：

| 方案 | v3 严格口径 | v4 放宽口径 | 变化 | 四级精确匹配 v3 → v4 |
|---|---|---|---|---|
| A 关键词规则 | 54% | 58% | +4 | 54% → 54% |
| B 纯大模型 | 78% | **83%** | +5 | 82% → **93%** |
| C RAG+大模型 | **85%** | 81% | −4 | **93%** → 89% |
| D 全量规则+大模型 | 83% | 81% | −2 | 93% → 86% |

**排序翻转是标签口径造成的，不是模型波动**（v3 两轮标准差 0–1%，v4 单轮）。
二分类里「疑似 = 放行」，所以：

- **B 变好**：它本来就很少阻断边界内容，5 条里有 3 条（M2/V1/B3）从"漏判"变成"判对"；
- **C/D 变差**：它们把 V1、B3 判成违规（阻断），在新口径下变成"过度阻断"。

这暴露了一个必须写进论文的事实：**"哪个方案更准"取决于上线策略，而不是模型本身**。
严格口径下 C 领先 7 点，放宽口径下 B 领先 2 点 —— 两者是同一批输出、同一套模型。

### 那"大方向"对不对？对，但理由不是准确率

| 与策略无关的指标 | A | B | C | D |
|---|---|---|---|---|
| 规则引用召回（可审计性） | 0% | **0%** | 47% | **60%** |
| 公开集（无关键词辱骂） | 50% | 67% | **71%** | **71%** |
| 平均 token | 0 | 980 | 1514 | 2084 |
| 成本/条 | 0 | 0.00149 元 | 0.00213 元 | 0.00266 元 |

结论：**保留 C（RAG+大模型）作为生产路径**，理由按重要性排序：

1. **可审计**：审核员终审时必须看到"违反了哪条规则"。B 的规则引用恒为 0，
   即使判对也给不出依据，无法满足人机协同的流程要求（这是功能需求，不是分数）。
2. **策略可调**：管理员改一条规则、加一个平台专有规则，行为立即变化，不用改提示词。
   这是"按平台规则预检"能力的基础，B 没有这个挂载点。
3. **对策略更稳健**：严格口径领先 7 点、放宽口径只落后 2 点；且落后发生在
   "把疑似判成违规"上 —— 在人机协同下这是安全方向（误报转人工，漏报才上线）。
4. **成本差可忽略**：每条贵 0.0006 元，千条多 0.6 元，在 50 元/月预算内不构成约束。

D 的规则召回更高（60% vs 47%），但 token 多 38%、四级精确匹配更低（86% vs 89%）：
全量下发规则会让模型"为了引用而多判"，所以 D 只作为消融对照，不作为生产方案。

**C 的两个明确待修项（不影响方向判断）**：
1. 多类混排召回不全（top_k=6 装不下）→ 按内容命中的类别数动态扩大 top_k；
2. 疑似/违规边界偏严（V1、B3 判成 2）→ 提示词增加"边界从宽、先判疑似"的约束后复测。
