## 七、结果分析（人工撰写）

### 1. 一句话结论

**RAG（C）在准确率与成本上取得最佳平衡**：85%（两轮完全一致）、四级精确匹配 93%，
比全量规则（D）少用 **28% 的 token**（1509 vs 2088）且准确率高 2 个点；
但它有一个明确的短板——**多类混排时召回不全**（75% vs D 的 100%）。

### 2. 分层证据：谁在哪一层赢

| 层级 | A | B | C | D | 说明 |
|---|---|---|---|---|---|
| 语境陷阱 | **25%** | 100% | 100% | 100% | A 把作品名/普法引用/新闻转述全判成违规 |
| 词表盲区 | 33% | 67% | **100%** | 83% | 软性引流、无关键词抄袭：只有 C 全中 |
| 分级边界 | 50% | 88% | **100%** | 75% | 个人分享 vs 带货：C 全部判对，D 有 1 条误判 |
| 多类混排 | 25% | 50% | 75% | **100%** | D 全中；C 漏掉一条（top-6 只覆盖了一部分类别） |
| 公开数据集 | 50% | 67% | **71%** | 69% | 隐晦辱骂对所有方案都难 |

**这张表直接说明了三件事**：
1. 关键词方案（A）不是"稍微差一点"，而是**在语义相关的能力上结构性缺失**（陷阱 25%、盲区 33%）；
2. **C 与 D 各有胜负区**：C 强在"少而准"（挑对规则、判定口径稳），D 强在"全而杂"（规则全覆盖但注意力被分散）；
3. 对**多类别混合内容**，D 更稳 —— 这是 C 必须补的短板。

### 3. 本次修复带来的变化（对照上一版）

三处修改让 C 的结果明显变好（上一版 C 为 79%，且有一次"个人分享被判违规"的策略失误）：

| 修改 | 作用 |
|---|---|
| **规则按平台过滤**（从 21 条降到 16 条：通用规则 + 本平台专属） | 之前把小红书/微博的专属规则也发给了"本平台"，等于让模型按别的平台标准判 |
| **元规则固定带上**（`suggestedLevel == 0`，如 BIZ-001 商业推广属性判定） | 修复"策略口径被检索挤掉"导致的判级失误；分级边界从 3/4 提升到 4/4 |
| **敏感词库作为词面关键词来源** | 规则里的示例词是完整短语（"加我微信领资料"），正文常写成"加我微信xxx领取"；敏感词库的短词兜住了这个缺口 |

### 4. 关键词定位实验（E vs C）

针对"长文本先定位再送模型"的方案，在 3 条长文样本、2 轮运行下：

| 方案 | 准确率 | 平均 token | 成本/条 |
|---|---|---|---|
| C RAG | 100% | 1990 | 0.00286 元 |
| **E RAG+关键词定位** | 100% | **1851（省 7%）** | 0.00265 元 |

**结论：思路成立，但在这个规模下收益很小。** 原因：
- 这几篇长文只有 2–4 段，定位后保留了"命中段 + 前后各一段"，实际剪掉的内容不多；
- 全文字数在 500–1000 字时，全文 token 成本本身只有约 2 分钱，省 7% 约等于 0.1 分钱；
- **收益会随篇幅增长而放大**：2000 字以上（8–10 段）时，保留 3 段大约能省 60–70% 的输入 token。
- 代价是**丢失整体语境**：分级判定（商业推广 vs 个人分享）需要看全文，只看片段可能判偏 —— 这一点必须在扩样本后专门验证。

**建议**：保留该模式作为可选开关，对超长文本（>1500 字）启用；常规篇幅直接用全文更稳。

### 5. 局限

1. 样本 52 条，自建部分单人标注（已生成复核问卷，待人工核对）；
2. 两轮运行结果几乎一致（±0.0%），说明判定稳定，但**两轮不足以估计置信区间**；
3. 公开样本仅覆盖辱骂/仇恨一类，且长度短、与自媒体文章分布不同；
4. 定位实验只有 3 条长文样本，结论只能算可行性验证；
5. 规则召回口径偏宽松（命中其他合理规则也算未命中）；
6. 仅 deepseek-flash 一个模型（pro 模型对比另出报告）。
