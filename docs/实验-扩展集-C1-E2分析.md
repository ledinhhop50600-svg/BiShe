# 扩展集对比实验分析（428 条，C1 / E2 / E1）

> 日期：2026-10-29
> 数据：`docs/eval/audit-results.json`；原始报告：`docs/实验-对比实验-v5-扩展集.md`
> 目的：把评测集从 52 条扩到 428 条，验证 C1（紧凑 RAG）、E2（B + 后置归因）与
> E1（B + 最小规则目录）能否在可追溯性和成本上替代原版 C。

## 一、评测集构成

| 来源 | 条数 | 标签 | 用途 |
|---|---|---|---|
| 核心自建 | 28 | 四级（0/1/2/3）+ 期望规则 | 业务硬样本：广告法、引流、违禁品、分级边界、长文 |
| ToxiCN | 200 | 二分类 toxic 0/1 | 真实短评论，扩大统计量 |
| COLD | 200 | 二分类 offensive 0/1 | 地域/性别/种族歧视，第二来源 |
| **合计** | **428** | 阻断 212 / 放行 216 | 核心看规则与分级，公开集看外部效度 |

公开集只参与二分类指标；`ruleRecall` 只统计核心集，避免没有期望规则的公开样本稀释结果。

## 二、七个方案

| 方案 | 规则上下文 | 说明 |
|---|---|---|
| A | 无 | 关键词 + 敏感词规则 |
| B | 无 | 纯大模型 + 分级策略 |
| C | top 6 完整规则 | 原版混合检索（关键词全部优先 + bge-m3） |
| C1 | top 4 紧凑规则 | 关键词限流/特异性排序 + 阈值 0.55 + 类别去重 + 召回安全阀 |
| E2 | 无（判定后归因） | B 判定 + 违规片段映射规则，引用回库校验 |
| E1 | 全量最小目录 | B + 只给规则编号/名称/类别/等级，模型直接引用 |
| D | 全量 16 条 | 全量规则（含条件、依据）+ 大模型 |

C1 的“召回安全阀”：短评论没有词面命中时，向量分可能普遍低于阈值；如果只剩元规则，补 2 条最高分的低分规则，避免整类漏判。

## 四、怎么解释

1. **没有单一赢家，但 E1 是最接近“三者兼得”的方案。** 它和 D 并列总体准确率 74.1%，token 只有 D 的 61%；
   核心集 96.4% / 91.7%，规则引用召回 83.3%，比 C 更准、更可追溯、更便宜。
2. **E1 的代价**：规则只给编号/名称/类别/等级，没有完整条件；模型可能把相近规则混用。
   公开集召回 56.0%，略低于 C 的 58.5%；误报 22 仍高于 B 的 14。它适合作为新的生产默认，
   但必须保留“引用编号回库校验”和人工终审。
3. **C1 是 C 的成本优化版，不是替代品。** 相对 C：token 1466 → 1177（-20%），规则召回 59.4% → 62.5%，
   核心准确率 85.7% → 96.4%；公开集召回 58.5% → 51.5%。适合核心业务/成本敏感路径，单独用会损失公开集召回。
4. **E2 的判定强、引用弱。** 核心准确率/召回与 B 同级（96.4% / 91.7%），token 与 B 相同（952）；
   规则召回只有 45.8%，说明关键词/字符重合的后置归因不够。它保留为“判定与归因分离”的研究方向。
5. **D 是可追溯性上限，不是默认。** 规则召回 79.2%、违规召回 60.8%，但 token 是 C 的 1.41 倍。
6. **关键词基线在公开集几乎失效**（召回 0.5%），再次说明“没命中关键词就放行”不可行。

## 五、结论与下一步

- **生产默认已从 C 切到 E1**：`AuditAgentService` 现在下发全量规则但要求 `useRag=false`、`catalogRules=true`；
  规则正文不再进 prompt，只给编号/名称/类别/等级，模型引用编号，依据仍回库查。
- **C1 保留为实验/可选配置**：如果产品更在意核心业务和 token，可让 C1 走核心内容；短评论/低置信场景回退 C/E1。
- **E2 继续补归因**：优先做规则向量匹配或紧凑目录，而不是继续加关键词；目标是规则召回 ≥70%。
- **分层路由可以作为下一步**：核心业务走 E1/C1，短评论/公开内容走 D/C，高危转人工；但必须先验证路由不会降低违规召回。
- **数据集继续补业务样本**：428 条里公开短评论占 400，广告法/引流/违禁品核心样本仍只有 28 条；
  下一步应补真实自媒体广告/带货文案（脱敏），而不是继续堆同分布短评论。
