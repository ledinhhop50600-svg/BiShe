# 扩展集对比实验分析（428 条，C1 / E2）

> 日期：2026-10-29
> 数据：`docs/eval/audit-results.json`；原始报告：`docs/实验-对比实验-v5-扩展集.md`
> 目的：把评测集从 52 条扩到 428 条，并验证 C1（紧凑 RAG）与 E2（B + 后置归因）能否在可追溯性和成本上替代原版 C。

## 一、评测集构成

| 来源 | 条数 | 标签 | 用途 |
|---|---|---|---|
| 核心自建 | 28 | 四级（0/1/2/3）+ 期望规则 | 业务硬样本：广告法、引流、违禁品、分级边界、长文 |
| ToxiCN | 200 | 二分类 toxic 0/1 | 真实短评论，扩大统计量 |
| COLD | 200 | 二分类 offensive 0/1 | 地域/性别/种族歧视，第二来源 |
| **合计** | **428** | 阻断 212 / 放行 216 | 核心看规则与分级，公开集看外部效度 |

公开集只参与二分类指标；`ruleRecall` 只统计核心集，避免没有期望规则的公开样本稀释结果。

## 二、六个方案

| 方案 | 规则上下文 | 说明 |
|---|---|---|
| A | 无 | 关键词 + 敏感词规则 |
| B | 无 | 纯大模型 + 分级策略 |
| C | top 6 完整规则 | 原版混合检索（关键词全部优先 + bge-m3） |
| C1 | top 4 紧凑规则 | 关键词限流/特异性排序 + 阈值 0.55 + 类别去重 + 召回安全阀 |
| E2 | 无（判定后归因） | B 判定 + 违规片段映射规则，引用回库校验 |
| D | 全量 16 条 | 全量规则 + 大模型 |

C1 的“召回安全阀”：短评论没有词面命中时，向量分可能普遍低于阈值；如果只剩元规则，补 2 条最高分的低分规则，避免整类漏判。

## 四、怎么解释

1. **没有单一赢家。** 公开集 400 条会把总体准确率拉向“短评论毒性”分布；核心集 28 条才反映广告法/引流/违禁品业务。
   B/E2 在核心集上准确率和召回最高，D/C 在公开集上更强。
2. **C1 达到了“更便宜”的目标，但不是全面替代。** 相对 C：token 1464 → 1178（-20%），规则召回 51% → 62.5%，
   核心准确率 85.7% → 92.9%；公开集召回 58.5% → 53.5%。它适合核心业务/成本敏感路径，不能单独覆盖所有短评论。
3. **E2 的判定质量保住了 B，但归因还不够好。** 核心集准确率/召回与 B 相同，token 与 B 相同；
   规则召回只有 47.9%，低于 C1 的 62.5% 和 D 的 82.3%。原因是后置归因依赖关键词/字符重合，
   遇到“评论区/主页/橱窗/偏见”这类没有直接规则示例词的片段会漏引。
4. **D 是可追溯性上限，不是默认。** 规则召回 82.3%、违规召回 60.8%，但 token 是 C 的 1.41 倍。
5. **关键词基线在公开集几乎失效**（召回 0.5%），再次说明“没命中关键词就放行”不可行。

## 五、结论与下一步

- **生产默认暂时保持 C**：C1 还没有在公开集召回上追平 C；E2 的引用召回也不够。
- **C1 保留为实验/可选配置**：如果产品更在意核心业务和 token，可让 C1 走核心内容；短评论/低置信场景回退 C。
- **E2 继续补归因**：优先做“紧凑规则目录（编号+一句话）”或规则向量匹配，而不是继续加关键词；
  目标是规则召回 ≥70%、核心召回不低于 B。
- **分层路由可以作为下一步**：核心业务走 C1/E2，短评论/公开内容走 C/D，高危转人工；但必须先验证路由不会降低违规召回。
- **数据集继续补业务样本**：428 条里公开短评论占 400，广告法/引流/违禁品核心样本仍只有 28 条；
  下一步应补真实自媒体广告/带货文案（脱敏），而不是继续堆同分布短评论。
