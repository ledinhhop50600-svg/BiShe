# 实验总览（阶段 5～8）

> 用途：把散落在各报告里的实验结论汇总到一页，方便写论文与答辩时快速定位。
> 详细数据见各报告；本页只给结论与文件索引。

## 一、审核实验（52 条评测集）

评测集：自建 28 条（分层设计）+ ToxiCN 24 条（正负各 12）；二分类口径为 `riskLevel >= 2` 阻断。

### 严格口径（v3，2 轮）

| 方案 | 准确率 | F1 | 四级精确匹配 | 规则召回 | 成本/条 |
|---|---|---|---|---|---|
| A 关键词规则 | 54% | 0.37 | 54% | 0% | 0 |
| B 纯大模型 | 78% | 0.72 | 82% | 0% | 0.00152 元 |
| C RAG+大模型 | **85%** | **0.82** | **93%** | 54% | 0.00211 元 |
| D 全量规则+大模型 | 83% | 0.79 | 93% | 60% | 0.00267 元 |

### 放宽口径（v4，1 轮，裁决后标签）

| 方案 | 准确率 | 四级精确匹配 |
|---|---|---|
| A | 58% | 54% |
| B | **83%** | **93%** |
| C | 81% | 89% |
| D | 81% | 86% |

**结论**：

1. 排序翻转是**标签口径**造成的（二分类里疑似=放行），不是模型波动；
2. 保留 C（RAG）的理由不是单一准确率，而是**可审计**（规则引用 47% vs B 的 0%）、
   **策略可调**、人工兜底下偏保守更安全；
3. D 规则召回更高，但 token 多 38%、精确匹配更低，只作消融；
4. C 的短板：多类混排召回不全（top_k=6 装不下）、疑似/违规边界偏严。

### 其他实验

- **模型对比**：deepseek-v4-pro 反而更差（B 65 / C 73 / D 79 vs flash 78 / 85 / 83）；
  不能假设更贵更强一定更好。
- **关键词定位消融**：3 条长文上准确率相同，E 省 7% token；篇幅更长时收益才明显。
- **长文本故障**：DeepSeek 默认思考模式会耗尽输出预算导致空内容；关闭后成本降 55%、耗时降 60%，
  准确率不变。
- **标注一致性**：15 条争议样本盲评，四级 Cohen's κ = 0.51；裁决后 5 条标签变更。

## 二、适配质量评估（4 篇 × 3 平台）

| 指标 | 结果 |
|---|---|
| 格式自检通过率 | 12/12（100%，`paper-20261019-v2`）；另一批 11/12（小红书长文 1111/1000 超限） |
| 单次适配耗时 | 约 6 秒（改写 + 合规预检） |
| 长文 #16 压缩比 | 小红书 0.38 / 公众号 0.94 / 抖音 0.42 |
| LLM 风格/保留/可读（1-5） | 4.00 / 4.58 / 4.67（区分度低） |
| 人工评分 | 待填（`docs/eval/adaptation-human-sheet.csv`） |

**结论**：格式约束可由程序稳定校验；长文压缩是弱项（出现过超限），必须保留"警告而不是静默通过"；
LLM 评分偏宽松，需人工评分对照。

## 三、人机协同指标（系统可观测）

- 智能体判定分布（0/1/2/3 + 失败）；
- 采纳率、改判率、人工判定占比；
- 每条判定的 token、耗时、模型；
- 改判原因原文。

改判率口径：改判 /（采纳 + 改判）；疑似转人工不算改判；人工判定不计入分母。

## 五、局限（论文必须写）

1. 审核评测集只有 52 条，自建样本由作者标注，统计显著性有限；
2. 公开集 ToxiCN 是短评论，与本平台文章分布不同；
3. 适配评估只有 4 篇稿件、3 个平台，LLM 评分区分度低，人工评分未完成；
4. 平台字数等约束会随平台改版变化，系统内数据需人工维护；
5. 实验脚本依赖本地 Agent 与后端，复现需按 `start.bat` 启动完整环境。
