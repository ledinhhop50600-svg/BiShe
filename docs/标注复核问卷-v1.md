# 标注复核问卷 v1

> 目的：评测集的期望等级目前由 AI 单独标注，需要你独立判断一批样本，用来计算「人类标注一致性」。
> 做法：逐题给出你的判断，不要参考任何「标准答案」（这里没有）。
> 你只需填数字：**0 通过 / 1 疑似 / 2 违规 / 3 严重**。

## 判定口径（请按这个来）

| 等级 | 含义 |
|---|---|
| **0 通过** | 正常内容；或虽然出现敏感词，但语境合法（作品名、引用法规、新闻报道转述、「最后一步」这类普通用法） |
| **1 疑似** | 有夸大/绝对化表述，但**没有卖货、没有引导交易、没有违法引导**（个人经验分享）—— 应交人工复核，默认倾向放行 |
| **2 违规** | 有商业推广/带货/交易引导**并且**含虚假承诺；或站外引流（引导加联系方式）；或明显侵权（未授权转载）；或低俗擦边 |
| **3 严重** | 违禁品交易（如处方药）；歧视性言论；违法违禁引导 |

> 一句话记法：**先看它是不是在卖东西、在拉人到站外；是 → 严；不是 → 看夸大程度给 0 或 1。**
