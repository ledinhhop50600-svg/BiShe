> 执行日期：2026-10-19　｜　环境：Windows 11 / JDK 17 / MySQL 8.0 / Node 22 / Python 3.11

## 一、执行方式

自动化脚本（项目根目录执行）：

```bash
python tools/verify_stage1.py     # 基础设施 / 健康检查
python tools/verify_stage2.py     # 认证、角色、菜单
python tools/verify_stage3.py     # 内容管理、状态机、权限、举报
python tools/verify_agent.py      # Agent 审核链路
python tools/verify_stage6.py     # 跨平台适配
python tools/verify_stage7.py     # 人机协同闭环
python tools/verify_account_revision.py  # 注册 / 个人中心 / 改稿重审
```

此外用浏览器实际走查了关键页面（登录、注册、工作台、适配、评测中心、规则库），
并手工模拟了「Agent 停机」的失败路径。
